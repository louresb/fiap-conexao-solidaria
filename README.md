# FIAP Conexão Solidária

Projeto desenvolvido no curso de Arquitetura de Sistemas .NET para o Hackathon da FIAP.

A plataforma centraliza a gestão de campanhas e doadores, o processamento de doações, a transparência e a auditoria das operações, apoiada por uma arquitetura escalável, observável e automatizada.
