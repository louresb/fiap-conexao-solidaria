# Principios de UX

## Direcao

A interface deve parecer um produto serio de impacto social, nao uma landing page generica de caridade. A experiencia precisa equilibrar emocao, clareza, transparencia e eficiencia transacional.

## Principios

1. CTA primario sempre claro.
2. Checkout isolado, sem navegacao desnecessaria.
3. Transparencia visivel antes da doacao.
4. Linguagem orientada a acao.
5. Progresso da meta com contexto de impacto.
6. Dados financeiros traduzidos em consequencias concretas.
7. Sem exploracao visual de sofrimento.
8. Ajuda de demo em modal/drawer, nao na superficie principal.
9. Mobile-first para doador e voluntario.
10. Dashboard denso e organizado para gestor.

## Checkout

Durante o pagamento, remover menus globais e links laterais. A tela deve conter apenas campanha, valor, metodo de pagamento, dados Pix, status, ajuda curta e saida controlada.

## Ancoragem de valores

Valores sugeridos devem ser contextualizados:

- R$ 35: contribui para itens basicos de um kit.
- R$ 75: ajuda uma familia por uma semana.
- R$ 150: apoia logistica e alimentacao.
- R$ 300: fortalece um lote de entrega.

O usuario sempre pode digitar outro valor.

## Transparencia

Toda campanha deve mostrar meta, arrecadado, executado, itens financiados, ultima atualizacao, status da prestacao de contas e documentos/evidencias disponiveis.

## Evitar

- Excesso de cards decorativos.
- Hero abstrato com gradiente sem imagem realista.
- Texto emocional sem dados.
- Banco de imagem artificial.
- Criancas expostas em situacao de vulnerabilidade.
- Dashboard vazio.
- Modal de demo visivel demais.
