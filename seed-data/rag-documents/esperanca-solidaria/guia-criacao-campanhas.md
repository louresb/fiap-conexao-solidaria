# Guia de criacao de campanhas

## Campos obrigatorios

- Titulo.
- Categoria.
- Objetivo social.
- Meta financeira.
- Regiao atendida.
- Publico beneficiado.
- Prazo.
- Plano de itens.
- Responsavel interno.
- Evidencias esperadas.

## Fluxo

1. Criar rascunho.
2. Completar plano financeiro.
3. Anexar justificativa social.
4. Submeter para aprovacao.
5. Revisao financeira/compliance.
6. Publicacao.
7. Monitoramento.
8. Prestacao de contas.

## Boas praticas

- Evitar linguagem apelativa.
- Explicar impacto de forma concreta.
- Informar como recursos serao usados.
- Definir marcos de atualizacao.
- Preparar textos para card, landing page e e-mail.
